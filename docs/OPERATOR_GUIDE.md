# Data Assistant · OPERATOR_GUIDE

**Проект:** ai-data-assistant
**Дата:** 2026-08-12

Руководство оператора: как менять поведение приложения без программирования, пересборки и рестарта контейнера.

---

## 1. Доступ к админке

1. Задайте `ADMIN_TOKEN` в `.env` (bootstrap, требует рестарта при первой установке).
2. Откройте `http://<host>:<port>/admin`.
3. Браузер запросит логин/пароль HTTP Basic:
   - пользователь: `admin`
   - пароль: значение `ADMIN_TOKEN`

Если `ADMIN_TOKEN` не задан — `/admin` отключён (403).

---

## 2. Операторские параметры

Все параметры ниже меняются в runtime — **применяются на следующем запросе без рестарта**.

| Параметр | Что делает | Пример |
|----------|------------|--------|
| **Специализация ассистента** | Роль/профиль в системном промпте | «финансовый аналитик», «эксперт по ритейлу» |
| **Системный промпт (override)** | Полностью переопределяет файл `prompts/v1/system.md` | свой текст с `{{specialization}}` |
| **Имя провайдера** | Имя провайдера в контенте; пусто = нейтрально | «OpenAI», «GigaChat» или пусто |
| **Модель** | Имя модели | `gpt-5-mini`, `gigachat-pro` |
| **Endpoint провайдера** | OpenAI-совместимый base_url | `https://api.openai.com/v1` |
| **Structured output** | Строгий контракт ответа (Вкл/Выкл) | Вкл для OpenAI; Выкл для провайдеров без поддержки |
| **Температура модели** | Креативность 0–2; отправляется только если явно задана | `0.3`, `0.7` |
| **Seed модели** | Воспроизводимость; пусто = не отправляется | `42` |
| **Сообщений истории** | Сколько последних сообщений передаётся в модель | `8` |
| **Лимит размера файла** | Максимум размера загрузки | `10MB`, `5MB` |

> **Портабельность температуры/seed.** Температура отправляется в запрос **только если оператор явно задал её в `/admin`**; иначе провайдер использует своё умолчание. Это важно: некоторые модели (например `gpt-5-mini`) поддерживают только умолчательное значение температуры и отвергают любое другое. Если модель не принимает `seed`, оставьте поле пустым. Невалидные значения (не число) дают явную ошибку в карточке.

## 3. Как изменить параметр

1. Откройте `/admin`.
2. В карточке параметра введите новое значение (или выберите из списка для bool).
3. Нажмите **«Сохранить»**.
4. Появится подтверждение «→ <новое значение>. Применится на следующем запросе без рестарта.»
5. Следующий запрос пользователя использует новое значение.

Кнопка **«Сбросить»** возвращает параметр к умолчанию из `.env`.

Поле **«Системный промпт (override)»** — многострочный текст (textarea). Доступны переменные `{{specialization}}` и `{{provider_attribution}}`. Если поле пусто (или сброшено) — используется файл `prompts/v1/system.md`.

## 3.1. Тест провайдера

После смены модели/endpoint проверьте, что провайдер отвечает:

1. Внизу `/admin` нажмите **«Тест провайдера»**.
2. Статус покажет либо «✓ Провайдер отвечает. Модель …, латентность N мс», либо «✕ Провайдер недоступен» с текстом ошибки.

Пинг отправляет минимальный запрос (`ping`) к текущим `base_url` + модель **без** `temperature`, `seed`, `response_format` и `max_tokens` — портабельно для моделей, не принимающих эти параметры. Тест **не записывается** в статистику использования.

---

## 3.2. Статистика использования

В верхней части `/admin` — dashboard «Статистика использования»:

- **Запросов** / **Ошибок** — счётчики обращений к модели.
- **Токенов всего** / **Промпт-токены** / **Комплит-токены** — расход токенов (если провайдер возвращает `usage`; иначе считается только запрос).
- **Последний запрос** / **Последняя ошибка** — временная метка и текст последней ошибки.

Счётчики хранятся в `storage/usage.json` (персистентно через volume) и обновляются при перезагрузке `/admin`. Используется для контроля расходов LLM. Диагностический «Тест провайдера» и локальные действия (анализ/графики без модели) в статистику не попадают.

## 4. Смена провайдера модели

Чтобы переключиться с OpenAI на другого провайдера (GigaChat, YandexGPT и т.п.):

1. `/admin` → **Endpoint провайдера** — укажите base_url провайдера.
2. `/admin` → **Модель** — укажите имя модели провайдера.
3. `/admin` → **Имя провайдера** — укажите имя для контента (или оставьте пустым).
4. `/admin` → **Structured output** — Выкл, если провайдер не поддерживает `json_schema`.

> `OPENAI_API_KEY` (секрет) меняется только в `.env` с рестартом — он не входит в операторские параметры.

Все остальные настройки применяются на следующем запросе без рестарта.

---

## 5. Правка промпта

Системный промпт — файл `prompts/v1/system.md` с плейсхолдерами:

- `{{specialization}}` — подставляется специализация (операторский параметр);
- `{{provider_attribution}}` — подставляется « от <имя провайдера>» либо пусто.

- **Dev/operator-режим:** правка файла применяется в runtime (mtime-кеш), без рестарта.
- **Production-режим:** промпт в образе; для правки нужна пересборка, **либо** монтируйте `./prompts:/app/prompts` (добавьте volume в `docker-compose.yml`), **либо** используйте **override в `/admin`** (поле «Системный промпт (override)») — override хранится в `storage/config.json` (персистентно через volume) и применяется раньше файла. Это рекомендуемый способ менять промпт в production без пересборки.

> Override проходит ту же интерполяцию переменных, что и файл. Сброс override в `/admin` возвращает использование файла.

---

## 6. Прямое редактирование config.json

Операторские параметры хранятся в `storage/config.json`. Правка этого файла напрямую (через файловый менеджер на сервере) также применяется в runtime — mtime-кеш подхватывает изменение на следующем запросе. Формат:

```json
{
  "assistant_specialization": "эксперт по ритейлу",
  "system_prompt_override": "Ты — ритейл-аналитик. {{provider_attribution}}",
  "openai_model": "gpt-5-mini",
  "structured_output": true,
  "openai_temperature": 0.3,
  "openai_seed": 42,
  "max_file_size": "10MB"
}
```

Отсутствующие ключи берутся из умолчаний `.env`. Секреты сюда **не писать**.

> `temperature` и `seed` отправляются в запрос модели только если ключ присутствует в `config.json` (для seed — и не равен `null`). Удалите ключ, чтобы провайдер использовал своё умолчание.

---

## 7. Что требует рестарта (НЕ операторские параметры)

- `OPENAI_API_KEY`, `ADMIN_TOKEN` — `.env` + рестарт.
- `APP_HOST`, `APP_PORT`, пути к каталогам, `RUNTIME_CONFIG_PATH` — `.env` + рестарт.
- Состав зависимостей (`requirements.txt`) — пересборка образа.
