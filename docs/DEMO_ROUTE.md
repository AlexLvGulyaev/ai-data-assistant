# Маршрут проверки демо — AI Data Assistant

Как быстро убедиться, что ассистент работает с вашими данными:
загрузить файл, запросить анализ и скачать результат.

## Маршрут проверки

1. **Открыть** [Live demo](https://data-assistant.alex-n8n.site) →
   **загрузить** свой файл (CSV, Excel, JSON или изображение) →
   **увидеть** превью: таблица и мета по файлу.
2. **Попросить** анализ с графиком в чате, например:
   - «дай сводку по выручке и построй самый показательный график»
   - «линейный график выручки по датам»
   → **увидеть**, что график построен по вашим данным; в шапке чата —
   провайдер и модель, которая отвечала.
3. **Попросить** отчёт («собери отчёт по файлу») → **скачать** DOCX
   с метриками и графиками.
4. **Загрузить** второй файл в тот же чат → **увидеть**, что можно
   сравнивать и анализировать несколько файлов вместе.

## Что ещё доступно

- Чипы действий в правом рельсе: «Построить график» с выбором типа
  (гистограмма, столбчатая, линейная, круговая) — график скачивается PNG.
- Честные ограничения (см.
  [USER_GUIDE.md](https://github.com/AlexLvGulyaev/ai-data-assistant/blob/main/docs/USER_GUIDE.md)):
  без активного файла анализ/график/отчёт не выполняются; действие,
  которого нет в системе, ассистент не выдумывает.
- Консоль оператора ([data-assistant.alex-n8n.site/admin](https://data-assistant.alex-n8n.site/admin),
  вход по `ADMIN_TOKEN`): runtime-конфиг (провайдер, модель, температура),
  редактор промпта, статистика расхода токенов — по
  [OPERATOR_GUIDE.md](https://github.com/AlexLvGulyaev/ai-data-assistant/blob/main/docs/OPERATOR_GUIDE.md).
- Полное руководство:
  [USER_GUIDE.md](https://github.com/AlexLvGulyaev/ai-data-assistant/blob/main/docs/USER_GUIDE.md).
