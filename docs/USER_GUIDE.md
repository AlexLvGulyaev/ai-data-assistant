## 💬 1. Что такое Data Assistant

Data Assistant — это AI-ассистент для анализа данных в чате. Он помогает:

- загрузить CSV, Excel, JSON или изображение и сразу увидеть preview;
- проанализировать таблицу — метрики, NaN-профиль, авто-инсайты;
- построить график (гистограмма, столбчатая, линейная, круговая) и скачать PNG;
- собрать DOCX-отчёт по файлу и скачать его;
- сохранить выводы в markdown.

Data Assistant не заменяет BI, не хранит ваши данные в облаке и не требует
регистрации. Вы пишете задачу на естественном языке — модель планирует
действие, приложение исполняет его локально.

## 🚀 2. Как открыть

1. Откройте [▶️ веб-интерфейс](https://data-assistant.alex-n8n.site).
2. Загрузите файл или сразу напишите запрос в чат.
3. Никакой регистрации и установки — нулевой порог входа.

![Главная: зона загрузки файла](screenshots/ADA_home_upload.png)

*Главная страница — зона загрузки и старт любого сценария.*

---

## 📤 3. Загрузка файла

1. Нажмите **«Файл или изображение»** в поле ввода (или перетащите файл).
2. Выберите файл: CSV, Excel (`.xlsx`/`.xls`), JSON, изображение
   (PNG/JPG/JPEG/BMP/GIF/WEBP).
3. Нажмите **«Загрузить и открыть preview»**.
4. Откроется preview: для таблицы — первые строки, число строк/колонок,
   numeric-колонки; для изображения — размеры, режим, формат.

![Preview CSV: таблица и мета](screenshots/ADA_preview_csv.png)

*Preview таблицы: первые строки, мета, numeric-колонки, кнопки действий.*

Файл становится **активным** — все действия (анализ, график, отчёт) применяются
к нему, пока не переключите на другой.

---

## 💬 4. Как задать вопрос

Введите запрос в поле ввода и нажмите **Отправить** (или Enter). Модель читает
контекст активного файла, сама выбирает действие и возвращает результат в чат.

Примеры запросов:

- «проанализируй файл»
- «построй круговую диаграмму выручки по категориям»
- «столбчатая диаграмма заказов по регионам»
- «линейный график выручки по датам»
- «собери отчёт по файлу»
- «сохрани выводы в markdown»
- «дай сводку по выручке и построй самый показательный график»

![Свободный диалог: модель выбрала действие](screenshots/ADA_chat_free_dialog.png)

*Свободный запрос — модель сама выбрала действие и обоснование.*

В шапке чата виден текущий провайдер и модель (например «GigaChat: GigaChat-Max»).

## 📊 5. Графики

График можно построить двумя способами:

- **Чипом в правом рельсе:** нажмите **«Построить график»** и выберите тип —
  «Гистограмма», «Столбчатая», «Линейный», «Круговая».
- **Текстом в чате:** напишите «построй круговую диаграмму выручки по
  категориям».

| Тип | Когда |
|-----|-------|
| 📶 Гистограмма | распределение числовой величины |
| 📊 Столбчатая | сравнение групп / средних по категориям |
| 📉 Линейный | динамика по оси (например, по дате) |
| 📈 Круговая | распределение долей по категориям |

![Круговая диаграмма в чате](screenshots/ADA_chat_pie.png)

*График в чате: inline-превью + карточка артефакта с кнопками «Открыть»/«Скачать».*

График сохраняется в PNG и появляется в разделе «Сохранённые артефакты» —
его можно открыть или скачать.

---

## 📄 6. Отчёты и сводки

- **«Создать DOCX»** (или «собери отчёт по файлу») — отчёт с метриками и
  графиками в редактируемом Word-документе. Кнопка «Скачать» в карточке.
- **«Сохранить summary»** (или «сохрани выводы в markdown») — выжимка диалога
  в `.md`-файле для дальнейшей автоматизации.

![DOCX-отчёт в чате](screenshots/ADA_chat_report.png)

*Карточка DOCX-отчёта с кнопкой скачивания.*

---

## 🗂️ 7. Несколько файлов

Можно загрузить несколько файлов в один чат. В правом рельсе в разделе
**«Файлы в чате»** они перечислены; нажмите на файл, чтобы сделать его
активным (подсвечивается). Все действия применяются к активному файлу.

![Несколько файлов в чате](screenshots/ADA_chat_multi_files.png)

*Раздел «Файлы в чате»: два файла, активный подсвечен.*

---

## ⚠️ 8. Ограничения

Data Assistant не умеет и не будет:

- строить дашборды 24/7 или хранить данные в облаке;
- работать без активного файла (анализ/график/отчёт требуют файла в чате);
- возвращать действие или график, отсутствующий в системе (реестр
  ограничивает модель);
- гарантировать ответ провайдера без настроенного ключа в `.env`.

> Свободный диалог и применение нового промпта требуют реального вызова LLM
> (тратят токены провайдера).

---

## ❓ 9. Что делать, если ответ не подошёл

1. Уточните вопрос («построй круговую диаграмму **выручки** по **категориям**»).
2. Проверьте, что нужный файл активен в разделе «Файлы в чате».
3. Выберите тип графика явно чипом, а не текстом.
4. Проверьте провайдера/модель в шапке чата; если провайдер не настроен —
   обратитесь к оператору (см. [`OPERATOR_GUIDE.md`](OPERATOR_GUIDE.md)).
